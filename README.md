# BPT ONE Interactive Prototype

A standalone, English-language prototype demonstrating a connected fleet workflow for management, operations, drivers, maintenance, and finance.

Open `index.html` in a browser. Start with **Driver App → Report an issue**, then use Maintenance, Operations, and Finance to follow trip #8801 through the simulated workflow. Use **Reset demo** to start over.

All data, integrations, alerts, and AI diagnostics are simulated for presentation purposes. The demo stores its state in browser local storage; no backend is required. The page uses web fonts when available and falls back to system fonts offline.
